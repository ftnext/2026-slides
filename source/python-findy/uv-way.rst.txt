:command:`uv sync` お試しあれ
============================================================

* :file:`pyproject.toml` があれば（:file:`uv.lock` なくとも）うまくいくことが多い
* ツールによらず使える、Pythonプロジェクトのメタデータを書くファイルです（`PEP 518 <https://peps.python.org/pep-0518/>`__）

.. https://packaging.python.org/ja/latest/glossary/#term-pyproject.toml

``uv sync`` の裏で
------------------------------------------------------------

* Pythonを見つける（ない場合はダウンロード）
* ロックファイル :file:`uv.lock` 作成
* 仮想環境 :file:`.venv/` を作り、ロックファイルと同期

**uvが仮想環境を有効にして** コマンド実行 [#uv-run-overview]_
----------------------------------------------------------------------

.. code-block:: shell
    :caption: 手動で有効化の必要なし

    $ uv run <command>

.. [#uv-run-overview] ``uv sync`` の上で仮想環境を有効化してコマンドを実行しています

仮想環境はuvにお任せ：依存の追加
------------------------------------------------------------

.. code-block:: shell
    :caption: venvやpipを扱う必要なし

    $ uv add httpx2 --bounds major

.. code-block:: toml
    :caption: :file:`pyproject.toml` に書かれる

    [project]
    dependencies = [
        "httpx2>=2.16.0,<3.0.0",
    ]

:file:`.venv/` と :file:`uv.lock` も作成・更新される

uvは **Pythonも管理** できる [#uv-python-commands]_
------------------------------------------------------------

.. code-block:: shell
    :caption: `Installing Python versions <https://docs.astral.sh/uv/guides/install-python/>`__

    $ uv python install 3.15 3.14

* どの環境でも同じコマンド [#uv-python-versions]_
* 既存のPython管理ツール（例：pyenv）とも共存します

.. [#uv-python-commands] https://docs.astral.sh/uv/reference/cli/#uv-python
.. [#uv-python-versions] ``3.15`` のような指定は ``uv run --python 3.15`` のように各コマンドにも指定できます（``UV_PYTHON`` も）

落ち穂拾い：uvと仮想環境
============================================================

* venvは使わずに仮想環境（ディレクトリ）を作る [#pep-405]_
* pipはない（uvが担えるので）
* uvコマンドを使う限りは **仮想環境は意識しなくてよくなっている**

.. [#pep-405] `PEP 405 – Python Virtual Environments <https://peps.python.org/pep-0405/>`__

uvと仮想環境 続き
------------------------------------------------------------

* 使う中で仮想環境をおかしくしてしまったら :file:`.venv/` を消してみる（``uv sync`` ですぐ復活。disposable）
* uvの作った仮想環境を直接触りたくなったら `uv venv <https://docs.astral.sh/uv/reference/cli/#uv-venv>`__ や `uv pip <https://docs.astral.sh/uv/reference/cli/#uv-pip>`__ コマンド

仮想環境との同期
------------------------------------------------------------

* ロックファイルと仮想環境を最新化できる（`Locking and syncing <https://docs.astral.sh/uv/concepts/projects/sync/>`__） [#locked-option]_
* `--frozen`: ロックファイルが最新でなくてもそのまま使って同期（CIで指定）
* `--no-sync`: 仮想環境を最新化せず

.. [#locked-option] `--locked`: ロックファイルが最新でないならエラー
