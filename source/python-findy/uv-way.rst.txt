Part2 uv登場
============================================================

煩雑な仮想環境管理をツールにやらせる流れが重なり、uvに至る

.. 流れはPyCon JPのスライドをどうぞ
    コマンドの形はPoetryが先駆け

uv（2024〜）
------------------------------------------------------------

* Astralという会社が提案
* 最初はRustで実装された高速なpipとして登場。0.3.0でPythonプロジェクト管理に機能増強
* Python環境構築を圧倒的に簡単にした

uvのインストール
------------------------------------------------------------

.. code-block:: shell

    $ curl -LsSf https://astral.sh/uv/install.sh | sh  # 他miseで入れる。などなど

uvは **Pythonも管理** できる
------------------------------------------------------------

.. code-block:: shell

    $ uv python install  # Python自体も管理

* 1つ1つダウンロードする代わりにuv
* 複数のPythonを管理するツール（例：pyenv）とも共存しますし、uvに切り替えられます

仮想環境はuvにお任せ
------------------------------------------------------------

venvやpipを扱う必要なし

.. code-block:: shell

    $ uv init my-project
    $ cd my-project
    $ uv add 'httpx2>=2.12.0'  # uv.lock 作成
    $ uv run <command>  # 仮想環境を有効にして実行
