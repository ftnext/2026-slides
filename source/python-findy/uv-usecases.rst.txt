----------------------------------------------------------------------

A. 一時的な仮想環境

`Running and installing applications as tools <https://docs.astral.sh/uv/guides/tools/>`__

.. [#alternative-pipx] pipxというツールでもできます（``pipx run``・``pipx install``）

🅰️ ``uvx`` （``uv tool run``）
------------------------------------------------------------

.. code-block:: shell

    $ uvx llm -m gpt-6-luna -f https://nikkie-ftnext.hatenablog.com/entry/2025/04/11/224643 'SNSでシェアする際のキャッチーなまとめを考えてください'

1. uvが **一時的な仮想環境** を作成
2. そこにCLIツールをインストールして実行

🅱️ ``uv tool install``
------------------------------------------------------------

.. code-block:: shell

    $ uv tool install llm
    $ llm -m gpt-6-luna -f https://nikkie-ftnext.hatenablog.com/entry/2025/04/11/224643 'SNSでシェアする際のキャッチーなまとめを考えてください'

1. uvが仮想環境を作成
2. そこにCLIツールをインストールし、**グローバルなパス** を通す

inline script metadataをサポートしたツール（例：``uv run``）は [#other-pep723-tools]_
------------------------------------------------------------------------------------------

1. ``requires-python`` を満たすバージョンで仮想環境を作成
2. ``dependencies`` を仮想環境にインストール
3. **その仮想環境でスクリプトを実行**

.. [#other-pep723-tools] ``hatch run``, ``pipx run``, ``pdm run`` （など）

uvはinline script metadataを書く
------------------------------------------------------------

.. code-block:: shell
    :caption: `uv init --script <https://docs.astral.sh/uv/reference/cli/#uv-init--script>`__

    $ uv init --script awesome.py

.. code-block:: python
    :caption: :file:`awesome.py`

    # /// script
    # requires-python = ">=3.14"
    # dependencies = []
    # ///

.. revealjs-break::

.. code-block:: shell
    :caption: `uv add --script <https://docs.astral.sh/uv/reference/cli/#uv-add--script>`__

    $ uv add httpx2 --script awesome.py

.. code-block:: python
    :caption: :file:`awesome.py`

    # /// script
    # requires-python = ">=3.14"
    # dependencies = [
    #     "httpx2>=2.10.0",
    # ]
    # ///
