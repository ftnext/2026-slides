Part2（続）使い倒すぜ、uv
============================================================

* 2026年のPython環境はこんなことができるんです！（2点紹介）
* uv以外にも方法はあります。uvを使っているなら、型を増やしましょう！

1️⃣PyPIにあるCLIツールの使用
============================================================

* 一時的な仮想環境
* 仮想環境+マシングローバルにインストール

.. pipxというツールでもできます（``pipx run``・``pipx install``）

``uvx`` （``uv tool run``） [#sakana-namazu]_
------------------------------------------------------------

    $ uvx openai@2.34.0 api chat.completions.create -m sakana-namazu -g user '台風とコロッケの関係は？'

1. uvが **一時的な仮想環境** を作成
2. そこにCLIツールをインストールして実行

.. [#sakana-namazu] 今回の例では環境変数 ``OPENAI_BASE_URL`` と ``OPENAI_API_KEY`` で `Sakana AIのNamazu <https://sakana.ai/namazu/>`__ に向けてます

``uv tool install``
------------------------------------------------------------

.. code-block:: shell

    $ uv tool install openai==2.34.0
    $ openai api chat.completions.create -m sakana-namazu -g user '台風とコロッケの関係は？'

1. uvが仮想環境を作成
2. そこにCLIツールをインストールし、**グローバルなパス** を通す

uv様々：自作CLIツールをエンジニアでない100人に配布
------------------------------------------------------------

.. code-block:: shell
    :caption: macOSの手順（Windows手順は省略）

    $ uv tool install cdcasasagi
    $ cdcasasagi --help

Pythonのインストールや仮想環境の管理を **uvが覆い隠して簡単に** してくれた

2️⃣inline script metadata
============================================================

* サードパーティライブラリを使ったスクリプトを書く際に推し
* シェルスクリプトの代わりに、 **サードパーティライブラリまで使えるPythonスクリプト**

.. _PEP 723: https://peps.python.org/pep-0723/

`PEP 723`_ - inline script metadata
------------------------------------------------------------

.. code-block:: python
    :caption: 特殊なコメント

    # /// script
    # requires-python = ">=3.12"
    # dependencies = [
    #   "httpx2",
    # ]
    # ///

inline script metadataをサポートしたツール（例：``uv run``）は [#other-pep723-tools]_
------------------------------------------------------------------------------------------

1. ``requires-python`` を満たすバージョンで仮想環境を作成
2. ``dependencies`` を仮想環境にインストール
3. **その仮想環境でスクリプトを実行**

.. [#other-pep723-tools] ``hatch run``, ``pipx run``, ``pdm run`` （など）

詳しくはPyCon JP 2024
------------------------------------------------------------

* 「`PEP 723（Inline script metadata）が拓く世界。Pythonスクリプトに必要な仮想環境をツールにおまかせできるんです！ <https://2024.pycon.jp/en/talk/89F3RQ>`__」
* `アーカイブ動画 <https://www.youtube.com/watch?v=Xdmr14cCq2g>`__

uvはinline script metadataを書く
------------------------------------------------------------

.. code-block:: shell
    :caption: `uv init --script <https://docs.astral.sh/uv/reference/cli/#uv-init--script>`__

    $ uv init --script awesome.py

.. code-block:: python
    :caption: :file:`awesome.py`

    # /// script
    # requires-python = ">=3.14"
    # dependencies = []
    # ///

.. revealjs-break::

.. code-block:: shell
    :caption: `uv add --script <https://docs.astral.sh/uv/reference/cli/#uv-add--script>`__

    $ uv add httpx2 --script awesome.py

.. code-block:: python
    :caption: :file:`awesome.py`

    # /// script
    # requires-python = ">=3.14"
    # dependencies = [
    #     "httpx2>=2.10.0",
    # ]
    # ///

inline script metadataはいいぞ
------------------------------------------------------------

* 完成したPythonスクリプトの **持ち運び** に超便利（コーディングエージェントのフックスクリプト、stdioのMCPサーバ実装）
* 実装中は ``PYTHONINSPECT=1 uv run awesome.py`` で **対話モードを立ち上げ** てデバッグも可能
