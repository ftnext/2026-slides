言語機能の追加：3.10の ``match``
------------------------------------------------------------

* マイナーバージョンアップで追加されるが、古い書き方も有効
* `Structural Pattern Matching <https://docs.python.org/ja/3/whatsnew/3.10.html#pep-634-structural-pattern-matching>`__ は3.9のサポートが終了した2025年10月以降本格的に使えるように

.. https://peps.python.org/pep-0596/
    As of 2025-10-31, 3.9 has reached the end-of-life phase of its release cycle.

.. code-block:: python

    def fizzbuzz(number):
        match number % 3, number % 5:
            case 0, 0: return "FizzBuzz"
            case 0, _: return "Fizz"
            case _, 0: return "Buzz"
            case _, _: return str(number)

------------------------------------------------------------

* **PyPI** （Python Package Index）がデフォルト

    * https://pypi.org/

* GitHub等で公開も可能

サードパーティパッケージのインストール
------------------------------------------------------------

.. code-block:: console
    :caption: `12. 仮想環境とパッケージ <https://docs.python.org/ja/3/tutorial/venv.html>`__

    $ source .venv/bin/activate  # 仮想環境の「有効化」
    (.venv) $ python -m pip install httpx2

pip
------------------------------------------------------------

* **パッケージマネージャ**（ただし機能は *弱い*）
* https://pip.pypa.io/en/stable/
* サードパーティパッケージだが、Python処理系に *バンドル* されている [#stdlib-ensurepip]_

.. [#stdlib-ensurepip] 標準ライブラリのensurepipによります

例：既存のPythonプロジェクトの開発に合流
------------------------------------------------------------

.. code-block:: console
    :caption: 仮想環境を作って依存をインストールして始める

    % git clone https://github.com/my-company/awesome-project.git
    % cd awesome-project
    % python3.15 -m venv .venv --upgrade-deps
    % source .venv/bin/activate
    (.venv) % pip install -e '.[dev]'

:file:`.venv/` には何がある？
------------------------------------------------------------

.. tree -L 2 .venv を加工

.. code-block:: txt
    :caption: python.org からmacOSにインストール（3.15.2）
    :emphasize-lines: 2,7,10-11

    .venv/
    ├── bin/
    │   ├── activate
    │   ├── pip
    │   ├── pip3
    │   ├── pip3.15
    │   ├── python -> python3.15
    │   ├── python3 -> python3.15
    │   └── python3.15 -> /Library/Frameworks/Python.framework/Versions/3.15/bin/python3.15
    ├── lib/
    │   └── python3.15/
    └── pyvenv.cfg

:file:`.venv/bin/python`
------------------------------------------------------------

* マシンにインストールしたPython処理系への **シンボリックリンク**
* :file:`.venv/bin/activate` は環境変数 ``PATH`` を更新して、:file:`.venv/bin/python` が見つかるようにしている
* 標準ライブラリも処理系のものを使う
* （TODO）有効化せずに :file:`.venv/bin/python` を直接実行してもよい

:file:`.venv/lib/python3.15/site-packages/`
------------------------------------------------------------

* サードパーティライブラリのインストール先のディレクトリ
* 仮想環境ごとに分かれているので、**バージョン違いが共存** する

.. python -m site で標準ライブラリ + 仮想環境のサードバーティライブラリが確認できる

**仮想環境は常に必要**
------------------------------------------------------------

* 新規のPythonプロジェクト
* Pythonスクリプト
* PyPIのパッケージをCLIツールとして使う

⚠️仮想環境ってrenameすると壊れます
------------------------------------------------------------

.. code-block:: console

    % .venv/bin/python -m pip install kojo-fan-art
    % .venv/bin/kojo-day kokoro
    % mv .venv myenv
    % myenv/bin/kojo-day kokoro
    zsh: myenv/bin/kojo-day: bad interpreter: /.../.venv/bin/python: no such file or directory

仮想環境は使い捨て（disposable）
------------------------------------------------------------

* インストールされたパッケージ一覧を書き出す
* 新しい名前の仮想環境に再度インストール

.. code-block:: console

    % .venv/bin/python -m pip freeze > requirements.txt
    % python3.15 -m venv .venv2
    % .venv/bin/python -m pip install -r requirements.txt

Part1 Python環境基礎 まとめ
============================================================

* Python処理系・pip・venv
* Pythonは1つのマシンにサードパーティパッケージのバージョン違いを共存させるために、仮想環境という仕組みを使っている
* 全てのPython使いが **仮想環境を理解して人力で管理** する時代が長かった（チュートリアルにも案内あり）

人力仮想環境管理 [#we-are-package-manager]_
------------------------------------------------------------

.. code-block:: bash
    :caption: `12.3. pip を使ったパッケージ管理 <https://docs.python.org/ja/3/tutorial/venv.html#managing-packages-with-pip>`__ [#why-python-m]_

    $ python -m venv .venv --upgrade-deps
    $ source .venv/bin/activate
    (.venv) $ python -m pip install httpx2
    (.venv) $ python -m pip freeze > requirements.txt
    (.venv) $ python -m pip uninstall httpx2
