サードパーティパッケージを扱うためのツール
------------------------------------------------------------

* pip：サードパーティだが、Python処理系にバンドルされている。パッケージをインストールする
* venv：標準ライブラリの1つ。*仮想環境* を作る

------------------------------------------------------------

    :caption: :file:`.venv/` というディレクトリができている [#venv-upgrade-deps]_

:file:`.venv/` には何がある？ [#python314-easter-egg]_
------------------------------------------------------------

.. tree -L 2 .venv を加工

.. code-block:: txt
    :caption: python.org からmacOSにインストール（3.14.7）
    :emphasize-lines: 2,7,11-12

    .venv
    ├── bin
    │   ├── activate
    │   ├── pip
    │   ├── pip3
    │   ├── pip3.14
    │   ├── python -> python3.14
    │   ├── python3 -> python3.14
    │   ├── python3.14 -> /Library/Frameworks/Python.framework/Versions/3.14/bin/python3.14
    │   └── 𝜋thon -> python3.14
    ├── lib
    │   └── python3.14/
    └── pyvenv.cfg

.. [#python314-easter-egg] easter eggです（拙ブログ `あなたが知らなくていい 𝜋thon の世界 <https://nikkie-ftnext.hatenablog.com/entry/python-3.14-pithon-maybe-you-dont-need-to-know>`__）

:file:`.venv/bin/python`
------------------------------------------------------------

* マシンにインストールしたPython処理系への **シンボリックリンク**
* :file:`.venv/bin/activate` は環境変数 ``PATH`` を更新して、:file:`.venv/bin/python` が見つかるようにしている
* 標準ライブラリも処理系のものを使う

:file:`.venv/lib/python3.14/site-packages/`
------------------------------------------------------------

* サードパーティライブラリのインストール先のディレクトリ
* 仮想環境ごとに分かれているので、**バージョン違いが共存** する

.. python -m site で標準ライブラリ + 仮想環境のサードバーティライブラリが確認できる

人力仮想環境管理を指南 [#we-are-package-manager]_
------------------------------------------------------------

.. code-block:: bash
    :caption: `12.3. pip を使ったパッケージ管理 <https://docs.python.org/ja/3/tutorial/venv.html#managing-packages-with-pip>`__ [#why-python-m]_

    $ python -m venv .venv --upgrade-deps
    $ source .venv/bin/activate
    (.venv) $ python -m pip install httpx2
    (.venv) $ python -m pip freeze > requirements.txt
    (.venv) $ python -m pip uninstall httpx2

Part1 Python環境基礎 まとめ
============================================================

* Python処理系・pip・venv

* 全てのPython使いが **仮想環境を理解して人力で管理** する時代が長かった（チュートリアルにも案内あり）
