Python公式チュートリアルが人力パッケージ管理を指南
------------------------------------------------------------

.. code-block:: bash
    :caption: `12.3. pip を使ったパッケージ管理 <https://docs.python.org/ja/3/tutorial/venv.html#managing-packages-with-pip>`__

    (.venv) $ python -m pip uninstall sampleproject
    (.venv) $ python -m pip freeze > requirements.txt

公式チュートリアルの範囲はこれで十分

2種類の依存：direct & transitive
------------------------------------------------------------

.. TODO 図 pip installで指定 vs directなパッケージが依存

``pip freeze`` で仮想環境内のパッケージをファイルに書き出す

``pip uninstall`` は指定したパッケージしか消さない
------------------------------------------------------------

* directな依存1つを指定（アンインストールされる）
* transitiveな依存は残ったまま

そもそも依存解決してから環境を同期すべきでは？
------------------------------------------------------------

* 手動管理の方法では複数のdirect依存からすべての依存を解決するプロセスがない
* 仮想環境に入ったバージョンを書き出す
* そっくりそのまま再現用（仮想環境はdisposableなので）

uv（2024〜）
------------------------------------------------------------

* Astralによる [#openai-astral]_。Rust製。Python自体も管理
* uvで管理しているプロジェクトであれば ``uv sync`` だけで再現（:file:`uv.lock`）
* ``uv run <command>`` で仮想環境の中でcommandが実行される

.. [#openai-astral] 2026年にOpenAIがAstralを買収しています

uv使うなら :file:`pyproject.toml` もね
------------------------------------------------------------

* 公式チュートリアルと互換なのは ``uv venv && uv pip install httpx2``
* ``uv init`` は :file:`pyproject.toml` も作る
* uvが書くことが多いが、新しい標準なので使いこなしましょう（``[tool.ham]`` テーブルで設定）
